# MoTe₂：前三带优先、高对称点邻域加权与逐带 overlap 图

保持六参数、二阶动能、全角度公共质量，沿用十角度 Heff。所有角度参与训练，没有重跑 TAPW，没有额外对称化，没有新增哈密顿量项。

主方案 rank_hs 的带权重为 w(n)=1/[1+exp((n-3.5)/0.15)]，n=1..12。前六带约为1、1、0.9656、0.03445、4.54e-5、5.78e-8。它是对带序号的平滑函数，明确优先前三带，不能称整个排序本征值目标在所有带交叉处可微。rank_nohs 使用相同带权重，作为邻域加权的对照。

邻域因子为 b(k)=1+0.75 exp[-d(k)^2/(2×0.06²)]，d(k) 是 k/G 到 Γ、M、K 中最近点的距离。中心相对远处为1.75倍；施加于路径能量和路径gap项，组内仍以权重总和归一。原来 Γ/M/K 的精确锚点项保留。绝对能量误差尺度仍为每角1meV，未引入偏向小角度的动能尺度容差。

energy_hs 是按参考能量平滑的物理对照：窗口中心仍为参考E3/E4中点，宽度 eta=max[(E3-E4)/(2 log(.97/.03)),0.003Etheta]。孤立时第三带权重为0.97、第四带为0.03；参考近简并时按有限宽度自然同时保留它们。两种新窗口都仅依赖参考数据或带序号，模型不能改变权重逃避误差。

颜色为固定层/Q基底中，同能量序号 model 与 Heff 的 |<u_ref,n|u_model,n>|²。全图统一0–1色条，不做能带配对、逐带相位/酉旋转优化，也不除以capture重新归一化。图中黑线为Heff，灰虚线为native SOC-TAPW；所有主能带图画top6。颜色线段使用相邻样点平均，样点和高对称点颜色保留各自实际数值。

单带overlap在简并子空间内依赖本征矢选择。因此每幅图下方另画top3投影capture F3、top3最小主角概率 sigma_min²、以及top4投影capture F4。F3允许前三带内部交换，F4帮助判断第三/第四带近简并。另有一页单独展示近简并群的颜色：参考或模型相邻gap<0.2meV时连接成群，群fidelity为两个群投影的迹除以群维数；它与逐带overlap分开展示，不把群fidelity冒充单带overlap。

本轮overlap是诊断和显示，不进入优化损失；未锁定单带身份。模型Q在拟合后加大，top12相对Gamma能量变化低于0.01meV。这只核对能量截断，不能保证近简并单带本征矢唯一。近简并处应结合群投影、F3/F4和最小主角概率阅读。

三种角度参数约束均重新拟合，使用四个初值，只按各自收敛训练目标选解。不是按overlap或未参与拟合的k点选解，也不声称全局最优。参数随角度变化组中，主方案新角度第三带平均overlap²约0.32，最弱top3方向约0.31；不能把这种失配仅解释为内部带交换。旧宽窗口第三带约0.83，但大角度能量误差较大。快速下衰减权重和稍增HS权重并没有同时解决能量、波函数与参数补偿问题。

angle_metrics.csv汇总逐角指标，overlap_by_k_and_band.csv保留每个k点前六带概率与群诊断，parameters.csv为物理参数。PDF含所有十角度的带色overlap图、权重函数、邻域因子、三种参数约束和参数趋势。没有计算Chern数或验证更小角度外推。

同一rank_hs损失还有另一组已收敛的局部解（wide初值）：新角度逐带平均overlap²约0.888、0.821、0.824，top3能量RMS约0.584meV，5.09°约1.996meV。它的训练总loss高于默认选中的低overlap分支，因此没有默默替换默认选择。两种解单独并排画出，说明仅凭能量训练loss无法唯一选定波函数更合理的分支。全部十角数据和参数均保留在ALTERNATE_SEED.json与CSV中。
