## 6.00898° 的两个来源版本

- `rigid/6.00898.vasp` 和 `rigid/6.00898_.vasp` 内容完全一致，仍保留两个来源文件名。
- `relaxed_cell/6.00898_relaxed.vasp` 与 `relaxed_cell/6.00898__relaxed.vasp` 的晶胞和坐标略有差异，均保留。
- 用户指定的 `5_6.01/soc/openmx.dat` 与 `5_6.01/nsoc/openmx.dat` 实际匹配 **`6.00898__relaxed.vasp`**。
- 两个 relaxed 文件都来自指定来源目录，不根据下划线猜测优劣或额外修改结果。

所有文件的源路径、SHA256、原子数及 SOC/NSOC 对应记录见根目录 `index.csv` 与 `manifest.json`。
