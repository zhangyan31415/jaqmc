# SnSe2 AA / M1: 9-parameter electron continuum model

Preserved export of an existing jointly fitted model; no refit was performed for this upload. `MODEL_INFO.json` gives the exact scientific scope and `COEFFICIENTS.json` preserves all controls and fit records. `reports/` contains bands, native overlap, parameter curves, saved predictions and original validation.

## Portable API and basis

Only Python + NumPy are needed. Load `hf_adapter.py` with importlib from this directory; call `hamiltonian(theta_deg,k_fractional)` and `reciprocal_basis(theta_deg)`. Labels such as 3.89 are resolved to exact catalog geometry. `model.parameters(theta_exact)`, `model.realspace(theta_exact,r_cartesian)` and `model.kinetic_tensors(theta_exact)` also expose the continuum form. Geometry APIs accept only the 12 catalog angles; coefficients interpolate within the fitted interval, not certified outside it.

H is an **electron conduction** Hamiltonian in eV, lengths in Angstrom. Its ascending eigenvalues are conduction energies up to one angle-dependent common energy zero. It has one effective orbital per layer and does not explicitly duplicate spectator spin. Component ordering is all layer-1 q points then all layer-2 q points, in each array's saved order. k is fractional in row-vector B: k_cart=k_fractional @ B. Plane waves are exp[i(k_cart-q) dot r]. No hidden layer/SOC matrix or absolute source import is needed.

## Exact real-space form and parameter count

h = [[K1+Ue+Uo,T],[T,K2+Ue-Uo]], with K_l=-A_parallel(e_l dot grad)^2-A_perp(e_l_perp dot grad)^2 and e_l=kappa_l/|kappa_l|. The two layer mass axes retain their actual rotations.

Let G0 be the first-star axis selected along kappa1-kappa2; Ga,Gb are the oriented oblique vectors chosen by `physical.stars`, with Ga-Gb=G0. The code, rather than an informal global rotation, fixes their signs.

Ue = 2 Sd[sin(Ga.r)-sin(Gb.r)] + 2 Va cos(G0.r) + 2 Sa sin(G0.r) + 2 Vc[cos(Ga.r)+cos(Gb.r)].
Uo = 2 Vd[cos(Ga.r)-cos(Gb.r)] + 2 Sl[sin(Ga.r)+sin(Gb.r)].
T = 2 wa cos(qa.r)+2 wb cos(qb.r), qa=(B1-B2)/2, qb=(B1+B2)/2.

Parameter order: A_parallel,A_perp,wa,wb,Sd,Va,Vd,Sa,Sl[,Vc]. Vc=0 in the nine-parameter model. A has units eV Angstrom^2; potentials eV. S denotes sine harmonics, not spin. Highest derivative is second order. Generic layer-odd terms and actual mass axes prevent exact independent layer-parity sectors.

For Fourier coefficients V_lm(G), h_lq,mq'=delta_lm delta_qq' (k-q)^T A_l(k-q) + V_lm(q'-q). The source-compatible Fourier masks are evaluated by `model.operators`; this fixes all signs. Source code `physical.py` contains additional unused helper families; only its M geometry is used here.

Angle controls use s=sin(theta/2)^2, x=(s-smin)/(smax-smin), u=x/[rho+(1-rho)x], and p=(1-u)^2 c0+2u(1-u)c1+u^2 c2. rho is fixed metadata, not an optimized physical coefficient. Both kinetic eigenvalues are exactly constant across all 12 angles (2 shared mass controls); other coefficients have three Bernstein controls each.

## HF and boundary conditions

This is a one-body input for an external HF calculation, **not** an HF solver or an interaction prescription. The supplied valley is M1 only. Other M valleys can be generated by consistent global rotations of lattice, masses and momenta; intervalley couplings/form factors are not inferred here.

T contains half-reciprocal vectors. Independent identical periodic boundary conditions on both layer components in the original moire cell are incorrect: primitive translations change the tunneling sign and require a compensating layer twist. `model.enlarged_cell` returns an area-two cell where every local harmonic is periodic. Do not merely double a mesh without tracking the associated folding and particle density per physical area.

The envelope density vertex is diagonal in the two layer components; for exp(i Q.r), q_out=q_in-Q in this plane-wave convention. Finite-cutoff missing states must be handled explicitly. If a band-projected HF calculation is used, recompute u(k+Q)^dagger D(Q) u(k) from these eigenvectors in this gauge. These effective envelope vertices omit microscopic atomic density form factors and interlayer finite-thickness screening. No interaction strength, dielectric constant, background subtraction, intervalley exchange or spin occupation is silently chosen.

## Scope and limitations

Original finite-model-Q all-angle candidate; the expanded-model-Q sensitivity in original Q_checks is retained and can be substantial. New seven-parameter package is preserved separately.

Quality is strongest for the first two spin pairs at theta <= 3.890238169 degrees; large-angle higher-band results must not be auto-selected by a high-throughput scan without consulting per-angle records. The spin-free model reproduces pair centers, not native SOC splitting. Native overlap is the unchanged finite-Q TAPW projection (no normalization to 1). Source-Q convergence is not established. Expanded **model** Q convergence does not certify expanded native TAPW source Q. Predictions have 61 path rows with the last Gamma repeated, 60 independent k points. The reports preserve both energy and gap errors rather than normalizing by a nearly flat single-band bandwidth.

Fresh portable verification and source hashes are recorded in `VERIFICATION.json` and `SOURCE_HASHES.json`. These verify the exported operator, not a new independent physical validation or a converged HF phase diagram.
